# Image credits

Provenance for the image assets shipped in this repository. The Unsplash Licence
does not require attribution, but an open project should be able to show where
its assets came from.

Assets are self-hosted deliberately. The site previously hotlinked its hero and
every Open Graph preview to a third-party CDN, which made the front page of an
Apache-2.0 project dependent on an external host staying up, under a licence
that could not be established.
